Conectar ao Google Sheets
Configure uma vez — cada cirurgia será enviada automaticamente para sua planilha.
1
Acesse sheets.google.com, crie uma planilha nova e deixe aberta.
2
No menu da planilha: Extensões → Apps Script. Apague todo o código existente e cole o código abaixo.
function doPost(e) { try { var ss = SpreadsheetApp.getActiveSpreadsheet(); var sh = ss.getSheetByName("Cirurgias"); if (!sh) { sh = ss.insertSheet("Cirurgias"); sh.appendRow(["Data","Paciente","Médico","Convênio","Prontuário", "Código","Procedimento","Valor","Total","Observações","Enviado em"]); } var d = JSON.parse(e.postData.contents); d.procs.forEach(function(p, i) { sh.appendRow([ d.data, d.paciente, d.medico, d.convenio||"", d.prontuario||"", p.cod, p.nome, p.val||0, i===0 ? d.total : "", i===0 ? d.obs||"" : "", new Date().toLocaleString("pt-BR") ]); }); return ContentService .createTextOutput(JSON.stringify({ok:true})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({ok:false, erro: err.toString()})) .setMimeType(ContentService.MimeType.JSON); } }
3
Clique em Salvar (ícone de disquete), depois em Implantar → Nova implantação.
4
Em "Selecionar tipo" escolha App da Web. Em "Executar como" deixe Minha conta. Em "Quem tem acesso" escolha Qualquer pessoa. Clique em Implantar e autorize quando solicitado.
5
Copie a URL da implantação (começa com https://script.google.com/macros/s/) e cole abaixo.
Importante: se já tinha uma implantação anterior, crie uma nova implantação após colar o código novo. URLs antigas não funcionam com o código atualizado.
